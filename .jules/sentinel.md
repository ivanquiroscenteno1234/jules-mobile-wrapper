## 2025-02-28 - Plaintext Password Storage in Test Presets
**Vulnerability:** The `/repos/{owner}/{repo}/presets` endpoint saved the `password` field from the request payload directly to `test_presets.json` in plaintext. Additionally, the `/presets` and `/repos/{owner}/{repo}/presets` GET endpoints returned this plaintext password to the client.
**Learning:** Even when a field isn't actively used or is explicitly skipped in one code path (like `save-as-preset`), generic CRUD endpoints (like `create_preset`) can still expose vulnerabilities by blindly saving and returning all model fields.
**Prevention:** Apply encryption to all password fields at the storage boundary, and explicitly redact sensitive fields (like passwords) before returning objects via API endpoints, following the same pattern used for credentials.
